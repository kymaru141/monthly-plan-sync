월중계획 자동 등록

학교 월중계획 문서를 구글 캘린더와 구글 할 일에 옮겨 주는 프로그램

English

월중계획 자동 등록 (Monthly Plan Sync) is a free desktop application for school staff in Korea. Monthly Plan Sync reads a school’s monthly plan document (.hwpx or .xlsx) on the user’s own computer, produces an editable spreadsheet so the user can review and correct each entry, and then creates the confirmed entries in the user’s Google Calendar and Google Tasks. It also lets the user undo a registration, removing only the entries it created.

The application has no server. It runs entirely on the user’s computer. The only outbound network traffic is to the Google Calendar and Google Tasks APIs.

How it uses Google data

  • calendar.calendarlist.readonly — choosing a destination calendar: lists the user’s calendars so the user can pick which one to write to.
  • calendar.events — creating events on the chosen calendar, checking for duplicates, and undoing a registration, which requires delete access. It deletes only the events it created.
  • tasks — creating a dedicated task list and tasks, and deleting on undo only the tasks it created.

Existing events and tasks are read only for the duplicate check before registering and the title comparison before undoing, and only their date and title, for the period being registered. They are not sent anywhere and not stored.

무엇을 하는 프로그램인가

학교에서는 매달 월중계획을 만듭니다. 한글 문서나 스프레드시트로 된 표에 날짜별 일정이 적혀 있습니다. 이것을 개인 일정 관리에 쓰려면 한 건씩 손으로 옮겨 적어야 합니다. 한 달에 백 건이 넘는 경우도 있습니다.

이 프로그램은 그 문서를 읽어 검토용 엑셀 파일을 만들고, 사람이 확인한 뒤 구글 캘린더와 구글 할 일에 한 번에 등록합니다.

쓰는 순서

① 월중계획 파일을 고릅니다  →  ② 만들어진 엑셀에서 일정·할 일·제외를 확인합니다  →  ③ 등록 버튼을 누릅니다

특징

  • 한글(hwpx)과 엑셀(xlsx) 두 형식을 읽습니다
  • 등록 전에 엑셀로 한 번 검토하므로 잘못 올라가는 일이 없습니다
  • 잘못 등록했을 때 되돌리는 기능이 있습니다
  • 사용자가 고친 분류를 기억해 다음 달에 미리 채워 줍니다
  • 부서별로 일정 색을 달리해 캘린더에서 구분됩니다

어디서 도는가

사용자의 PC에서 도는 데스크톱 프로그램입니다. 서버가 없습니다. 문서를 읽는 일도, 엑셀을 만드는 일도 모두 그 PC 안에서 끝납니다. 바깥으로 나가는 통신은 구글 캘린더와 구글 할 일에 일정을 넣고 빼는 것과, 그에 앞서 필요한 만큼 읽는 것뿐입니다.

구글 계정 권한

프로그램이 요청하는 권한과 그 쓰임입니다.

Google Calendar
캘린더 목록 읽기		 등록할 캘린더를 사용자가 고를 수 있도록 캘린더 목록을 읽습니다.
Google Calendar
일정		 사용자가 고른 캘린더에 일정을 만듭니다. 등록 전 겹침 확인과 되돌리기 전 대조를 위해, 그 기간 기존 일정의 날짜와 제목을 읽습니다. 되돌리기를 눌렀을 때 이 프로그램이 만든 일정을 지웁니다.
Google Tasks 기한만 있는 업무를 할 일로 만듭니다. 할 일 목록을 읽고, 없으면 전용 목록을 하나 만듭니다. 등록 전 겹침 확인과 되돌리기 전 대조를 위해, 그 기간 기존 할 일의 마감일과 제목을 읽습니다. 되돌리기를 눌렀을 때 이 프로그램이 만든 할 일을 지웁니다.

캘린더 전체 권한은 요청하지 않습니다. 기존 일정 · 할 일은 위 두 확인에만 읽으며, 바깥으로 보내지 않고 저장하지 않습니다.

지우는 대상은 이 프로그램이 등록한 것으로 기록에 남아 있는 항목뿐입니다. 지우기 전에 구글에서 제목을 다시 읽어 대조하고, 사용자가 손으로 고친 항목은 건너뜁니다.
