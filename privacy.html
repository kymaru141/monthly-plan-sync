「월중계획 자동 등록」(이하 “이 프로그램”)은 학교 월중계획 문서를 읽어 사용자의 구글 캘린더와 구글 할 일에 일정을 등록하는 데스크톱 프로그램입니다. 이 방침은 이 프로그램이 사용자의 정보를 어떻게 다루는지 설명합니다.

요약

이 프로그램에는 서버가 없습니다. 제작자는 사용자의 어떤 정보도 수집하거나 전송받지 않습니다. 모든 처리는 사용자의 PC 안에서 이루어지며, 바깥으로 나가는 통신은 사용자의 구글 계정에 일정을 넣고 빼는 것뿐입니다.

1. 제작자가 수집하는 정보

없습니다. 이 프로그램은 사용자의 PC에서만 동작하며 제작자가 운영하는 서버가 존재하지 않습니다. 사용자의 문서 내용, 일정, 구글 계정 정보, 사용 기록 중 어느 것도 제작자에게 전송되지 않습니다. 분석 도구나 오류 수집 도구도 포함되어 있지 않습니다.

2. 접근하는 구글 사용자 데이터와 그 이유

요청 권한 쓰임
calendar
Google Calendar		 ① 등록할 캘린더를 사용자가 고를 수 있도록 캘린더 목록을 읽습니다.
② 사용자가 고른 캘린더에 월중계획 일정을 만듭니다.
③ 사용자가 되돌리기를 눌렀을 때, 이 프로그램이 등록한 일정을 지웁니다.
④ 지우기 전에 해당 일정을 다시 읽어 제목이 그대로인지 대조합니다.
tasks
Google Tasks		 ① 기한만 있는 업무를 할 일로 만듭니다.
② 할 일 목록을 읽고, 없으면 전용 목록을 하나 만듭니다.
③ 사용자가 되돌리기를 눌렀을 때, 이 프로그램이 등록한 할 일을 지웁니다.

삭제 권한이 필요한 이유

이 프로그램의 핵심 기능 중 하나는 잘못 등록한 것을 되돌리는 것입니다. 한 번에 수십에서 백 건이 등록되므로, 잘못되었을 때 손으로 하나씩 지우는 것은 현실적이지 않습니다. 되돌리기가 없으면 사용자가 실제 업무용 캘린더에 이 프로그램을 쓰기 어렵습니다.

삭제 대상은 이 프로그램이 등록한 것으로 로컬 기록에 남아 있는 항목으로 한정됩니다. 지우기 전에 구글에서 해당 항목을 다시 읽어 제목을 대조하고, 사용자가 손으로 고친 항목은 건너뜁니다. 프로그램이 만들지 않은 일정은 어떤 경우에도 지우지 않습니다.

3. 정보가 저장되는 곳

모두 사용자의 PC, 프로그램 폴더 안입니다.

token.json 구글 인증 토큰. 매번 로그인하지 않도록 보관합니다.
credentials.json 프로그램 자신의 식별 정보. 사용자 정보가 아닙니다.
등록내역 파일 되돌리기에 필요한 기록. 등록한 계정 주소, 캘린더 식별자, 항목별 구글 식별자, 성공·실패 여부가 들어 있습니다.
검토용 엑셀 월중계획 문서에서 읽어낸 일정 목록.
설정·학습 파일 사용자가 고친 분류와 부서별 색 설정.

이 파일들은 사용자의 PC를 벗어나지 않습니다. 제작자를 포함한 누구에게도 전송되지 않습니다.

4. 제3자 제공

없습니다. 이 프로그램은 구글 API 외의 어떤 외부 서비스와도 통신하지 않습니다. 광고, 통계, 추적 기능이 포함되어 있지 않습니다. 사용자 데이터를 판매하거나 다른 목적에 사용하지 않습니다.

5. 구글 API 제한 사용 정책 준수

이 프로그램의 구글 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책을 따르며, 여기에는 제한 사용(Limited Use) 요건이 포함됩니다. 구글에서 받은 정보는 사용자에게 보이는 이 프로그램의 기능을 제공하는 데에만 쓰이며, 광고를 포함한 다른 목적에 쓰이지 않고, 사람이 읽지 않으며, 제3자에게 넘기지 않습니다.

This application’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The application runs entirely on the user’s own computer. No user data is transmitted to, stored on, or read by the developer or any third party.

6. 권한을 거두는 방법

  • 프로그램 폴더의 token.json을 지우면 저장된 인증이 사라집니다.
  • 구글 계정의 타사 앱 및 서비스에서 「월중계획 자동 등록」의 액세스 권한을 삭제하면 연결이 완전히 끊어집니다.
  • 프로그램 폴더를 지우면 등록내역과 설정을 포함한 모든 파일이 함께 사라집니다.

이미 캘린더에 등록된 일정은 사용자의 것이므로 권한을 거둬도 지워지지 않습니다. 필요하면 권한을 거두기 전에 프로그램의 되돌리기 기능을 쓰거나, 구글 캘린더에서 직접 지우시면 됩니다.
